# Superset

> Superset is an open-source, terminal-first code editor for the AI-agent era. It runs 100+ CLI coding agents (Claude Code, Cursor, OpenCode, Gemini, Copilot, Mistral Vibe) in parallel, each isolated in its own Git worktree. A standalone CLI, a TypeScript SDK, and a hosted MCP server let agents and automation manage workspaces, tasks, terminals, and scheduled automations programmatically. Backed by Y Combinator (Spring 2026).

## APIs

- [Superset Agent API (docs)](https://docs.superset.sh): Hosted REST + MCP surface at api.superset.sh (v2) for workspaces, tasks, agents, terminals, automations, projects, and hosts. Auth via OAuth 2.1 or API keys (sk_live_*).
- [MCP Server](https://docs.superset.sh/mcp): Hosted HTTP MCP server at https://api.superset.sh/api/v2/agent/mcp.
